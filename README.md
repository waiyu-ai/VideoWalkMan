# VideoPlaylist

SwiftUI iOS app for building video playlists from the Photos library. Built with **Apple frameworks only** (no CocoaPods, SPM, or binary libraries).

## Requirements

- iOS 16.0+
- Physical iPhone recommended for Photos video playback
- Free Apple ID for sideloading (7-day certificates)

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` (done automatically in CI).

## Build & sideload (Windows — no Mac required)

Everything compiles on GitHub’s free **macOS** runner. You never need Xcode locally.

1. **Push to a public GitHub repo**  
   Free macOS Actions minutes require a **public** repository. Private repos consume paid minutes.

2. **Run the workflow**  
   Open the **Actions** tab. The `iOS Build` workflow runs automatically on push to `main`, or start it manually with **Run workflow**.

3. **Download the IPA**  
   When the run finishes (about 3–5 minutes), download the artifact **VideoPlaylist-unsigned-ipa** and unzip it to get `VideoPlaylist-unsigned.ipa` (or rename to `VideoPlaylist.ipa`).

4. **Sideload with Sideloadly**  
   Install [Sideloadly](https://sideloadly.io) on your Windows PC. Connect your iPhone by USB. Drag the IPA into Sideloadly, enter your free Apple ID when prompted. Sideloadly signs the app and installs it.

5. **Trust the certificate on iPhone**  
   **Settings → General → VPN & Device Management → [your Apple ID] → Trust**.

6. **Refresh every 7 days**  
   Free Apple ID signing expires after 7 days. Repeat steps 3–5, or keep [AltServer](https://altstore.io) running on your PC so AltStore can refresh over Wi‑Fi without a cable.

### Signing note

This pipeline produces a **truly unsigned** IPA. **No GitHub secrets, certificates, or provisioning profiles are required.** Sideloadly (or AltStore) performs all signing locally with your free Apple ID.
